# Yasin Makhloufi — academic website

Source of the personal academic website of Yasin Makhloufi, PhD, geoscientist in the Department of Earth Sciences at the University of Geneva ([GE-RGBA group](https://www.unige.ch/ge-rgba/)).

The site is a single static page (`index.html`) with its photos in `assets/img/`, served by GitHub Pages. No build step on GitHub's side.
